# PR titles

Use this skill when drafting or reviewing a pull request title. It helps the reader see the intended behavior, the problem a maintenance change solves, or the part a refactor contributes to a later change.

In this checkout, invoke `$pr-titles` in Codex or `/pr-titles` in Claude Code. Supply a diff, a PR description, or a short description of the change. Both agents can also select the skill when a request calls for a PR title.

For use across projects, symlink the [skill directory](skills/pr-titles) into your personal skills directory. The repository’s two discovery links point to this same source.
